# 2-内置工具参考

Snow App 内置一套 MCP 工具，供 AI Agent 执行文件操作、终端命令、
网络搜索、浏览器自动化等任务。本文列出全部内置服务器与工具。

## 1. 工具命名规则

内置工具全名为 `{服务器id}-{工具名}`，例如 `filesystem-read`。
部分服务器 id 包含 `-`（如 `user-interaction`），解析工具名时按
内置服务器列表做**最长前缀匹配**消除歧义。

### bash

| 工具全名                | 用途                                 | 关键参数                                                                                        |
| ----------------------- | ------------------------------------ | ----------------------------------------------------------------------------------------------- |
| `bash-terminal-execute` | 执行终端命令（构建、测试、包管理等） | `command`、`description`、`workingDirectory`、`timeout`、`detach`、`isInteractive`、`sessionId` |

> **Shell 来源**：命令始终在「终端设置」中配置的 Shell 内执行；留空时自动
> 检测系统默认终端（Windows：PowerShell → CMD → Git Bash → COMSPEC）。
> 该工具不接受 `shellPath` 参数——如需指定 Shell 打开交互式终端，请使用
> `terminal-open`。

> **常驻会话**：PowerShell 家族（pwsh / Windows PowerShell）连续命令复用同一个
> 常驻热 shell 会话，省掉每条命令的冷启动（实测单条 ~400ms → ~40ms）；每条命令
> 仍会重置工作目录，而进程级状态（环境变量、`$global:` 变量）按交互终端语义在
> 命令间保留；命令需要 stdin 输入（`Read-Host`、密码提示等）必须传
> `isInteractive:true`。`detach` 与 `isInteractive` 仍走一次性进程路径。

> **工作目录**：`workingDirectory` 可省略，省略时默认使用当前项目的工作区目录
> （SSH 项目为远端工作区路径）；仅当会话未绑定项目工作区时才必须显式指定。

### grep

| 工具全名      | 用途                      | 关键参数                                                                               |
| ------------- | ------------------------- | -------------------------------------------------------------------------------------- |
| `grep-search` | 使用 ripgrep 搜索文件内容 | `pattern`、`description`、`path`、`fileGlob`、`caseSensitive`、`isRegex`、`maxResults` |
| `grep-find`   | 按 glob 查找文件路径      | `pattern`、`description`、`path`、`maxResults`、`searchAll`                            |

> **释义**：`description` 让用户不必解读正则——模型用用户语言写一句话说明本次
> 搜索在找什么，界面用它替代原始正则展示检索意图（正则本身仍可在卡片中查看）。
> 模型漏填时只回退展示正则，**不影响搜索执行**。

> **glob 语义**：`grep-find` 的 `pattern` 不含 `/` 时匹配任意层级的文件名
> （如 `*.ts`），含 `/` 时匹配相对搜索根的路径（如 `src/**/*.{ts,tsx}`）；
> 结果只含文件路径。
>
> **过滤与全量**：默认跳过 `node_modules`、`.git`、`target`、`dist` 等重目录
> （ripgrep 后端还会跳过 `.gitignore` 忽略的文件）；设置 `searchAll: true` 可
> 关闭这些过滤做无损全量查找（大仓库会明显变慢）。

#### Frame 定位与信任边界

- `browser-frames {instanceId?}` 枚举当前 guest 的主 frame 与子 frame，返回 `frameId`、`parentFrameId`、`isMainFrame`、脱敏 `url`/`name`。ID 是不透明、绑定标签页和文档的句柄，不是 CDP frame/session ID。
- `evaluate`、`get_tab_content`、`wait`、`click`、`type`、`hover`、`select_option`、`upload-file`、`scroll`、`press_key`、`get_css_styles`、`audit` 可传 `frameId`；`devtools` 的 `snapshot`/`ax`/`console`/`network` 可传。`press_key` 发往该帧当前焦点元素；`scroll` 与 `get_css_styles` 的 `ref` 使用该帧的 AX 快照；`audit` 的 axe/SEO/最佳实践只检查目标帧文档，控制台错误也按该帧统计。`console`/`network` 只返回该帧的 CDP 记录（`console` 不含无帧归属的 Log 条目）；无帧归属的回退数据会显式失败。省略时仍选择主 frame。导航、重载、移除或 guest 重建后重新枚举；失效 ID 明确报 `FRAME_STALE`，绝不回退主 frame。
- 脚本、正文与等待（包括省略 `frameId` 的主 frame）优先通过主进程 `WebFrameMain.executeJavaScript` 执行。AX、元素 ref、文件上传及真实输入使用精确匹配的 CDP context/session；OOPIF 仅附加到当前 guest 的 iframe target。frame target session 由共享管理器持有，调试器断开（含 DevTools 抢占）或 guest 销毁时清理；对象句柄按操作释放，已验证文档的 CDP target 在该文档被替换前复用。Network/Fetch/Console/Dialog 事件按所属帧 session 采集与响应，网络详情键、控制台 `cdpFrameId` 与弹窗 `frame` 字段用于区分主帧与 iframe；OOPIF 的 Log 条目按 target 帧归属，根会话中无帧归属的 Log 条目不带 `cdpFrameId`。弹窗列表返回 `dialogId`，响应可带 `dialogId` 定向处理，省略时对所有 pending 弹窗应用同一响应。带 `frameId` 的动作中 `expect` 在目标帧内评估，URL/标题/加载/事件仍按顶层页面观察，快照文本取自目标帧。会话失效时显式失败，不回退主帧。不复制认证票据，不读取 Cookie/认证存储。
- Frame AX 的 `fr-...` ref 仅属于该 frame 的最近一次快照，重拍会使旧 ref 失效；click/type/hover/select/upload 使用 ref 时同时传原 `frameId`。即使 `verbose=true`，frame AX 也不返回输入 value。普通主 frame 原有 ref 契约不变。
- URL 用户信息、query、fragment 和敏感路径片段统一去除/掩码；工具出口递归脱敏敏感键、Bearer/JWT 和凭据形态文本；仅 screenshot 操作保留 PNG 二进制数据。不要用 evaluate 读取或返回认证资料。表达式关键词检查与输出脱敏不是任意 JavaScript 的安全沙箱，也不能保证识别所有自定义短字符串秘密。
- 坐标沿各层 frame owner 换算并检查遮挡；旋转、倾斜、镜像和 perspective frame 明确拒绝，不伪报点击成功。`webSecurity` 保持启用；DevTools 抢占、不可执行/失效 frame、无法匹配的 CDP 上下文会明确失败。
- Electron 打包版本为 37.10.3。上述说明是实现契约；编译验证不代表所有真实网站、沙箱 iframe、OOPIF、CSS 变换和平台组合已经完成运行时验收。frame 操作超时不会终止任意页面 JavaScript，避免提交长期运行/无限循环表达式。

### sub-agents

| 工具全名                   | 用途                                                                                                                                                         | 关键参数                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------- |
| `sub-agents-activate`      | 激活子代理独立执行任务（必填 `summary` 会作为子代理会话的标题与摘要显示在侧边栏子代理列表）；可选 `acceptance` 附带验收清单                                  | `agentId`、`summary`、`prompt`、`acceptance` |
| `sub-agents-listTeammates` | 查询当前会话中**正在运行**的子代理（同会话可见，其他会话不暴露）                                                                                             | 无                                           |
| `sub-agents-sendMessage`   | 给同会话仍在运行的队友子代理发消息；以 Pending 消息在对方当前轮次结束时投递，并带发送者身份前缀                                                              | `conversationId`、`message`                  |
| `sub-agents-listSubAgents` | 列出当前会话的子代理（含本次应用运行期间已结束的），返回 `status`（running/completed/failed/cancelled）、`resumable` 与验收快照（逐项状态/证据/`satisfied`） | 无                                           |
| `sub-agents-continue`      | 向当前会话的子代理发消息并恢复：已结束时按原配置（模型/工具/系统提示词）与完整历史重新激活；仍在运行则排队为 Pending 消息；可选 `acceptance` 追加/修正验收项 | `conversationId`、`message`、`acceptance`    |

`agentId` 必须从主会话系统提示词注入的子代理清单中选择（内置 `agent_general` 为通用兜底）；不确定时可先调用 `config-list`（scope=`subAgents`）查询。

**验收清单与证据回执（可选）**：`sub-agents-activate` 可传 `acceptance: [{ id, description, required? }]`（最多 20 项，`required` 默认 true）。附带清单时，子代理收到的每个工具结果前会出现宿主分配的证据 id（`[evidence ev-N]`），并须在最终回复末尾用 `acceptance` 代码块逐项回执 `status`（completed/incomplete/blocked/unverified）、`observation`、`evidence`（证据 id 列表）与 `reason`。宿主收尾时校验证据 id 是否来自该子代理会话的真实工具执行记录：`completed` 缺少有效证据一律降级为 `unverified`，未回执的项同样保持 `unverified`，绝不默认为通过；回执块会从交回主控的摘要中移除。工具结果返回 `acceptance`（逐项状态、证据精简预览、`satisfied`）与 `acceptanceSatisfied`；`satisfied` 仅在所有 required 项均 completed 且引用有效证据时为 true，否则附带 `instruction` 要求主控继续同一子代理补测。证据 id 有效只证明该工具调用确实发生，仍需主控判断证据是否支持结论。`sub-agents-continue` 也可传 `acceptance` 追加或修正清单项；已记录状态保留，补测只更新未完成项（不重复已完成步骤）。未附带清单的任务行为完全不变（无证据标记、无回执字段）。清单与证据日志是本次应用运行期的运行时状态，应用重启后不恢复，需在 `continue` 时重新传入。

同会话通信受**会话隔离**约束：`listTeammates` 看不到其他会话的子代理，`sendMessage` / `continue` 跨会话调用会被拒绝。应用重启后，子代理会话可恢复并继续（见 [5-配置Hooks与子代理](../2-使用指南/5-配置Hooks与子代理.md)）。

**作用域**：支持 `symbol` 的工具在省略 `filePath` 的寻址模式下也接受可选 `workspaceRoot`。该参数必须是存在的绝对本地目录，拒绝相对路径、文件和 SSH；省略时使用当前项目根，无可靠根时要求显式提供。它不提升项目开关或子代理权限，也不表示跨所有项目搜索。

**结果安全**：内部寻址先检查完整候选，展示上限不能成为唯一性依据。`warnings`、`incomplete`、partial/failed 和 `partial_symbol_search` 不得解释成“没有问题/只有一个目标”。没有验证过的 `selectionRange` 时，候选范围只作导航并要求 `requiresExplicitCoordinates`；不要把 Flat range 起点当作重命名坐标。UI 展示完整性与警告，进程 running 不是索引 ready。

**新鲜度**：`ensure_open` 比对实际全文并发送 didOpen/didChange；工作区请求同步已打开文件并关闭已删除文件。诊断不再读写持久 `lsp_diagnostic_cache`，旧表/历史数据不由本次变更删除；接受重新诊断成本，避免单文件 mtime/size 掩盖依赖或配置变化。

`lsp-workspace-symbols` 的 ID 不变，三语显示名为“全局符号搜索 / 全域符號搜尋 / Workspace Symbol Search”。旧 `lsp-definition`、`lsp-type-definition`、`lsp-implementation` 已合并为 `lsp-goto{kind}`。详细当前行为与待验收矩阵见 [LSP 接入设计](../4-架构与开发/7-LSP外部语言服务器接入设计.md)。

#### 调用与结果契约（2026-09-26）

- **条件 MUST**：语义任务在对应工具可见且支持目标语言/操作时必须使用 LSP；禁用、权限排除、未覆盖、启动退避或健康失败时说明局限并使用可见兜底，不扩大权限。
- **严格输入**：诊断仅接受 `filePaths` 数组（1..30）；`symbols` 接受 `filePaths` 数组（1..10）；`hover` / `goto` 接受 `items` 数组（各 1..10）；`references` 接受 `items` 数组（1..5）。单个目标也必须放在一项数组中；不再接受单点参数。拒绝缺失数组、错误类型、空数组/条目及超限，不静默截断。路径数组按物理文件去重，保留首次请求顺序。
- **稳定输出**：所有上述操作都返回 `batch:true` 的批次封套（`files` 或 `items`），包含整体 `status`、计数与逐目标结果；每项目标独立保留 complete/partial/failed/ambiguous 状态及错误或警告。任一项歧义、失败或部分结果都不得伪报整体 complete。`lsp-rename` 仍是单符号操作，跨文件编辑遵循预览凭证与部分应用契约。
- **有界执行**：只读批量任务使用目标并发上限 3，并按输入顺序返回。引用和大纲汇总统计不得将失败或不完整项当成成功。

两组工具名称同步上述 11 项语义，ID 与历史 key 不删除；goto 可按 kind 显示定位定义/定位类型定义/查找实现。只读批次限制并发 3、按输入顺序返回；当前行为以 LSP 设计 §0.7 和已实现代码为准，本文不代表真实语言服务器运行时已验收。

| `imagegen-image-describe` | 用视觉模型分析磁盘上的图片并返回结构化描述（布局/配色/字体/间距/组件），用于「读取设计稿 → 理解设计 → 编码还原前端」等工作流；主模型支持视觉时直接用主模型（advancedModel），否则复用主 API 配置的 vision 通道（chat / responses / anthropic / gemini），带 blake3 缓存（按图片内容 + prompt 区分，同图换问法会重新分析） | `path`（必填）、`prompt`（可选分析重点） |

| 参数                | 类型           | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`            | string（必填） | 生成描述；提供参考图时为编辑指令（**一次调用 = 一张图**；需要多张图请并行发起多次调用）                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `prompts`           | array          | **兼容保留，不推荐**：逐请求不同提示词（1-8 项，覆盖 `n`）。生成多张**各不相同**的图片请**并行发起多次调用**（每次一张、各自独立的 `prompt`），不要用本参数在单次调用里塞多个提示词                                                                                                                                                                                                                                                                                                                                                            |
| `images`            | array          | 参考图 `[{data, mimeType}]`（base64，不含 `data:` 前缀；兼容带前缀的 data URL）或 `[{path, mimeType}]`。`path` 可为可信的绝对磁盘路径，或来自 `[Reference image #N for imagegen-generate: ...]` 引用块的安全 `upload/...` 相对路径；相对路径必须以 `upload/` 开头并拒绝 `..` 穿越，服务端会自动读取并编码，无需复制大段 base64。图生图/编辑用；运行时每组上限 **14 张**、单张编码数据约 20 MiB（工具描述建议 AI 单次 ≤5 张，仅为兼容部分服务商更严格的限制）；OpenAI 走 `/images/edits`、Gemini 走 `inlineData`；提供 `requestImages` 时被忽略 |
| `requestImages`     | array          | **兼容保留，不推荐**：逐请求独立参考图组 `[[组1...], [组2...], ...]`（每组的形状同 `images`），组数必须 = 请求数（= `prompts` 长度或 `n`，1-8）。多张不同源图分别编辑/重绘请**并行发起多次调用**（每次一张、各自带独立的 `images`）；未提供时所有请求共用 `images`                                                                                                                                                                                                                                                                             |
| `model`             | string         | 覆盖设置中的模型；OpenAI：`gpt-image-1`/`gpt-image-2`/`dall-e-3`；Gemini：`gemini-3.1-flash-image`（Nano Banana 2）/`gemini-3.1-flash-lite-image`（Lite）/`gemini-3-pro-image`（Pro）/`gemini-2.5-flash-image`（旧版）。**能力规则（不支持的请求会 400）**：`dall-e-3` 仅文生图（不接受参考图）且每次仅生成 1 张；`imagen-*` 同样仅文生图                                                                                                                                                                                                      |
| `provider`          | enum           | `auto`（默认，按配置推导）/ `openai` / `gemini`，后端切换                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `size`              | string         | OpenAI：`1024x1024`、`1024x1536`、`1536x1024` 等；Gemini：`1K`/`2K`/`4K`（imageSize）或 `16:9`、`1:1`、`9:16` 等（aspectRatio）                                                                                                                                                                                                                                                                                                                                                                                                                |
| `quality`           | enum           | `low` / `medium` / `high` / `auto`；OpenAI 仅 gpt-image 系列生效，Gemini 仅接受 `low`/`medium`/`high`（`auto` 被忽略）                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `outputFormat`      | enum           | OpenAI：`png`（默认）/ `jpeg` / `webp`；dall-e 与 Gemini 忽略                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `outputCompression` | number         | OpenAI JPEG/WebP 压缩率 0-100                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `n`                 | number         | **兼容保留，不推荐**：1-8（默认 1）。生成多张图片请**并行发起多次调用**（每次一张），不要调大 `n`；n>1 仅对**同一提示词**拆成 n 个**并发子请求**（每请求 1 张，绕开上游不支持单请求多图），整批返回并各自落库；n>1 时自动关闭流式预览；`dall-e-3` 恒为 1。传 `prompts` 数组时由数组长度决定请求数                                                                                                                                                                                                                                              |
| `personGeneration`  | enum           | Gemini：`dont_allow`（默认）/ `allow_all` / `allow_adult`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `webSearch`         | boolean        | Gemini 联网搜索（Grounding with Google Search），默认取设置                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `stream`            | boolean        | 流式预览（OpenAI `partial_images` SSE / Gemini `streamGenerateContent`），默认取设置；dall-e 与图生图忽略                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `inputFidelity`     | enum           | OpenAI 编辑保真度：`low` / `high` / `auto`（默认）；`gpt-image-2` 不支持（恒为高保真）                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `background`        | enum           | OpenAI：`opaque`（默认）/ `transparent` / `auto`；透明背景需模型支持（`gpt-image-2` 等不支持时自动降级为 `opaque`）                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `moderation`        | enum           | OpenAI：`auto`（默认）/ `low`（更宽松过滤）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `seed`              | number         | 确定性种子，复现结果                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `thinkingLevel`     | enum           | **仅 Gemini 图像模型**：写入 `generation_config.thinking_level`；各模型支持档位不同（Nano Banana 2.1：`minimal`/`medium`/`high`；Gemini 3 Pro Image：`high`）。OpenAI 图像接口无此参数                                                                                                                                                                                                                                                                                                                                                         |
| `imageSearch`       | boolean        | Gemini 3.1 Flash Image：Google Image Search 联网参考（需展示搜索建议）                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

> **配置与暴露规则**：渠道需 `enabled` + `apiKey` + `model` 三者齐备才算可用；
> 多个渠道可同时启用，AI 按请求选择（未指定渠道时按渠道顺序取第一个可用渠道，也可传 `provider` 指定）；
> 均未配置时 `imagegen-generate` 从模型工具列表隐藏。
> 不支持的模型能力会在**发送前**自动校验（`dall-e-3`/`imagen-*` 传参考图
> 本地拦截并提示换模型；`dall-e-3` 的 `n` 自动收敛为 1）；仍出现的上游 400
> 会附带具体修复提示（多图数量 / 图像输入 / 尺寸 / 质量）。
> 图形界面配置见 [2-使用指南/9-图像生成](../2-使用指南/9-图像生成.md)；
> 也可通过 `config` 工具的 `imagegen` scope 读写（见上文，apiKey 脱敏）；
> 多图生成通过**并行多次调用**实现（一次调用 = 一张图），受设置中的「最大并发生成数」限制（1-8，默认 4），超出排队、完成一张补一张；`n`/`prompts`/`requestImages` 为兼容保留参数，不推荐使用。
> **Imagen 已弃用**：`imagen-*` 模型 2026-08-17 关停，请用 Nano Banana 系列。

### memory

| 工具全名        | 用途                                                            | 关键参数                                                                               |
| --------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `memory-save`   | 保存跨会话的项目记忆（同标题自动合并去重）                      | `title`、`content`、`kind`、`importance`、`tags`、`sessionId`                          |
| `memory-search` | 按关键词检索项目记忆（打分排序）                                | `query`、`kind`、`status`、`limit`                                                     |
| `memory-list`   | 分页浏览项目记忆                                                | `status`、`kind`、`limit`、`offset`                                                    |
| `memory-update` | 更新记忆条目（缺省字段保持不变）                                | `memoryId`（字符串或数组）、`title`、`content`、`kind`、`importance`、`status`、`tags` |
| `memory-delete` | 删除记忆（**破坏性**，需用户确认）；`memoryId` 可为数组批量删除 | `memoryId`（字符串或数组）、`confirmed`                                                |

> **项目隔离与注入**：所有 memory 工具按当前会话的项目（`directory_id`）
> 隔离读写，模型无法跨项目访问；项目上下文由调用链注入，工具参数不
> 携带 projectId。主会话的系统提示词末尾自动注入 `## Project Memory`
> 章节：`importance >= 3` 的 active 条目按重要性取头部（上限 30 条 /
> 4000 字符），尾部附带当前会话 ID 引导 `memory-save` 传递 `sessionId`
> （记忆溯源锚点）。空记忆库时注入简短引导。子代理不注入该章节。
>
> 章节按会话冻结：会话首次注入时渲染并存快照（`memory_prompt_snapshots`
> 表），之后每轮复用同一份文本——会话中新增/修改记忆不会改动已发送的
> 提示词前缀，整个会话的 prompt cache 持续命中，新记忆只对之后新建的
> 会话生效（当前会话可用 `memory-search` 查询最新内容）。
>
> 删除会话时，确认弹窗会统计该会话保存的记忆数并让用户选择是否连带
> 删除（默认保留）；注入快照属于会话自身，随会话无条件清理。
>
> `memory-memory-delete` 为破坏性操作：必须先通过
> `user-interaction-askUserQuestion` 获得用户明确同意，再携带
> `confirmed: true` 重试；不带确认参数的调用会被拒绝。
>
> `memoryId` 支持字符串或数组：`memory-delete` 数组批量删除共用一次确认；`memory-update` 数组批量时套用同一补丁（`kind` / `importance` / `status` / `tags`），整批要么全部成功要么全部回滚，`title` / `content` 仅允许单条更新（标题是去重键）。
>
> **用户侧入口**：侧边栏「项目记忆」打开的记忆库支持按关键词检索（标题 /
> 标签 / 内容，复用 `memory-search` 的打分排序，可与状态 / 类别筛选叠加，
> 命中处高亮）；对话输入 `/memory` 按会话溯源列出本会话（含子代理与
> WorkFlow 节点）保存或更新的记忆，可展开全文并跳转到记忆库定位。

### decision

| 工具全名            | 用途                                                                                                                      | 关键参数                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `decision-evaluate` | 用决策模型对证据回答类型化问题，返回结构化答案：predicate 给概率，choice 给选项与各选项概率，score 给分值、档位与各档概率 | `questions`（必填）、`evidence`（必填）、`model`（可选） |

参数说明：

| 参数                                 | 说明                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------- |
| `questions[].name`                   | 问题 id（字母、数字、`_`、`-`，≤64 字符，不可重复），答案按它返回               |
| `questions[].type`                   | `predicate` / `choice` / `score`                                                |
| `questions[].choices`                | choice 专用：2-50 个 `{value, description?}`                                    |
| `questions[].levels`                 | score 专用：2-10 个 `{label, description?}`，低档在前                           |
| `questions[].whenTrue` / `whenFalse` | predicate 可选：判定为真 / 假的标准                                             |
| `questions[].images`                 | 题级图片路径：只随该题发送（如每题一张候选图，与共享参考图对比）                |
| `evidence.text`                      | 文本证据                                                                        |
| `evidence.json`                      | 结构化证据（真实 JSON 值）                                                      |
| `evidence.images`                    | 所有问题共享的图片路径（如截图、参考图）                                        |
| `model`                              | 决策模型 id 或名称；省略时使用「设置 > API > 决策模型」中的**决策工具默认模型** |

> **图片证据**：仅支持 PNG / JPEG（按文件头识别），单图 ≤16 MiB、单次 ≤16 张不同图片，
> 处理后总量 ≤24 MiB；长边超过 1568 px 时等比缩小后再发送。路径可为绝对路径、
> 相对项目根的路径或 `upload/...`，且必须位于项目工作区（含关联项目，WorkTree
> 模式下限定为绑定的 worktree）、应用数据目录、图片库或系统临时目录内。图片不可读、
> 格式不支持、超限或越界时整次报错（带路径），**不会发出请求**；图片只在显式调用
> 本工具时读取与发送。
>
> **两个 provider 都支持图片**：OpenAI Decisions 走 `input_image`（共享证据放
> `input`，题级图片让 `instructions` 变为 `input_text` + `input_image` 数组）；
> 只支持 GA 前协议的端点不接受题级图片的数组写法（会返回 400），此时自动改发兼容
> 形态：题级图片连同「Image for question "&lt;题名&gt;" (&lt;文件名&gt;)」标注一起放进共享
> `input`，并在该题说明里指出这些标注，随后该端点沿用这一形态；
> TypeSafe Jev（1.13 起）走请求顶层 `assets` 与引用串，并自动带
> `TypeSafe-Danger-Zone-Images: true` 请求头。Jev 额外要求图片两边都 ≥280 px，
> 不满足时本地提前报错。单题被拒答（refusal）时该题返回 `refused: true`，
> 其余题照常返回。
>
> 本工具会把本地证据发往外部决策模型 API，因此不在只读免审批列表中。

## 5. 与外部 MCP 工具的区别

外部 MCP 服务器工具由用户在 **MCP 设置** 中添加
（见 [2-使用指南/1-配置 MCP 服务器](../2-使用指南/1-配置MCP服务器.md)），
工具名前缀为服务器名（如 `dbx-search_context`），与内置工具通过
内置服务器列表前缀匹配的方式区分。
