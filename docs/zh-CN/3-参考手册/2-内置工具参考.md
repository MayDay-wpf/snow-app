# 2-内置工具参考

Snow App 内置一套 MCP 工具，供 AI Agent 执行文件操作、终端命令、
网络搜索、浏览器自动化等任务。本文列出全部内置服务器与工具。

## 1. 工具命名规则

内置工具全名为 `{服务器id}-{工具名}`，例如 `filesystem-read`。
部分服务器 id 包含 `-`（如 `user-interaction`），解析工具名时按
内置服务器列表做**最长前缀匹配**消除歧义。

## 2. 服务器总览

按注册顺序列出：

| 服务器 id          | 说明                                                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `filesystem`       | 本地文件读写（read / replace_edit / create）                                                                      |
| `bash`             | 终端命令执行                                                                                                      |
| `todo`             | 会话任务清单管理                                                                                                  |
| `grep`             | 文件内容搜索（ripgrep）                                                                                           |
| `websearch`        | 网络搜索与网页抓取                                                                                                |
| `browser`          | 内置浏览器自动化（嵌入式 Electron 浏览器）                                                                        |
| `user-interaction` | 向用户提问（阻塞式交互）                                                                                          |
| `sub-agents`       | 激活子代理独立执行任务                                                                                            |
| `codebase`         | 代码库语义搜索（嵌入索引；**仅项目启用代码库索引且已建立索引后暴露**）                                            |
| `codelens`         | 代码诊断与符号定位                                                                                                |
| `app-control`      | 应用控制（备忘录 / 模式 / 设置页 / 定时任务 / 项目）                                                              |
| `config`           | 全局配置读写（文件：settings/snowcfg/proxy/app/custom-headers/system-prompt/theme/language/permissions/lsp-config/buddy/personalization；数据库：subAgents/hooks/imagegen；委托：skills；只读：logs） |
| `terminal`         | 终端自动化（持久 PTY 会话标签页，区别于 bash 的一次性命令）                                                       |
| `imagegen`         | AI 图像生成与编辑（OpenAI / Gemini 多渠道；**所有渠道均未配置时按需隐藏**）                                       |
| `skills`           | 技能（Skill）加载与执行（**动态注册**：无已启用技能时从工具列表隐藏）                                             |

### config

| 工具全名        | 用途                                                                                                                                                                                                                | 关键参数                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| `config-list`   | 列出可管理配置域（settings/snowcfg/proxy/app/custom-headers/system-prompt/theme/language/permissions/lsp-config/buddy/subAgents/hooks/skills/logs/imagegen/personalization）与各域键；传 `scope` 查看单域详情与当前值（敏感键脱敏） | `scope`、`projectId`                 |

| `config-set`    | 写入指定域/键（白名单 + 类型校验 + 写前自动备份 + 原子写，**写入成功后清理本次备份**）；`settings.mcpServers` 自动同步应用数据库立即生效；`subAgents`/`hooks`/`imagegen` 域直接写应用数据库立即生效（同样写前备份、成功后清理）；`personalization` 域 `key=role` 整体替换 `~/.snow/ROLE.md`（值必须为字符串，写后下一个对话生效） | `scope`、`key`、`value`、`projectId` |
| `config-delete` | 删除指定域/键；**破坏性操作，必须携带 `confirmed: true`（仅限调用方先通过 `user-interaction` 的 `askUserQuestion` 获得用户明确同意后才可携带），否则被拒绝**；写前自动备份、成功后清理。**`imagegen` 域的 delete 是清空全部图像生成渠道（不是只删命名键）**；`skills` 域 delete 卸载技能；`logs` 域 delete 删除日志文件；`subAgents`/`hooks` 域直接删除数据库记录；`personalization` 域 delete 删除 `ROLE.md`（恢复默认规则） | `scope`、`key`、`confirmed`、`projectId` |

> **安全机制（配置变更保护）**：为避免 AI 误改/误删用户配置，
> config 工具内置以下约束——
> - **删除二次确认**：`config-delete` 必须先经用户确认（`askUserQuestion`）
>   并以 `confirmed: true` 调用，未确认一律拒绝；`imagegen` 的 delete 是
>   **全量清空所有渠道**（非单键删除），更需谨慎。
> - **写前备份**：`config-set` / `config-delete` 在写入前自动把当前值备份到
>   `~/.snow/.config-backups/`（文件型与 DB 型 scope 均覆盖），作为写入期间
>   的临时安全网；**写入成功并验证后删除本次备份**，历史/并发残留由
>   每文件最多 10 份的上限清理兜底。
>
> **结构校验**：`settings.codebase`、`custom-headers.schemes`、
> `system-prompt.prompts`、`lsp-config.servers` 在写入时会做**嵌套结构深度
> 校验**（对已知字段逐一检查类型，如 `codebase.embedding.dimensions` 必须是
> 数字），防止 agent 写坏内部字段；未知字段放行以保持前向兼容。
>
> **项目级 settings**：给 `settings` scope 的 `mcpServers` / `sensitiveCommands`
> 传 `projectId` 可读写**项目级**配置（应用数据库，立即生效，与 UI 项目级设置
> 同源）：`mcpServers` 为全量替换（value 为 `{name: {type,url,command,args,env,headers,enabled,timeoutMs}}`）；
> `sensitiveCommands` 为全量替换（value 为数组，元素 `{commandId, pattern, description, enabled}`，
> commandId 匹配全局规则时作为 enabled 覆盖，其余为项目自定义规则）；
> 其余键不支持 projectId（会明确报错）。

### terminal

管理右侧面板中的终端标签页（持久交互式 PTY 会话，跨多次调用保持存活），
与 `bash-terminal-execute`（单次一次性命令）互补。省略 `tabId` 时作用于最近聚焦的标签页。

| 工具全名              | 用途                                                                                 | 关键参数                                                         |
| --------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| `terminal-open`       | 打开新终端标签页（持久登录 shell 会话；省略 `cwd` 时使用当前项目目录；省略 `shellPath` 时使用终端设置或系统默认）                | `cwd`、`shellPath`                                               |
| `terminal-send`       | 向终端 PTY 发送输入（如同用户键入；省略换行时后端自动补 \n 触发执行）                 | `input`（必填）、`tabId`                                         |
| `terminal-read`       | 读取终端屏幕缓冲区的当前可见文本（ANSI 已剥离；非完整回滚历史）                       | `tabId`、`waitMs`（0-60000）                                     |
| `terminal-resize`     | 调整终端 PTY 尺寸（同时更新 PTY 进程与显示）                                         | `cols`（1-500）、`rows`（1-200）、`tabId`                        |
| `terminal-wait`       | 等待终端进入空闲（静默期无新输出），用于探测长命令是否结束                            | `tabId`、`timeoutMs`（≥1000，默认 30000）、`idleMs`（100-5000）  |
| `terminal-close`      | 关闭终端标签页并终止其 PTY 进程                                                      | `tabId`                                                          |
| `terminal-focus`      | 切换到指定终端标签页（前台激活）                                                     | `tabId`（必填）                                                  |
| `terminal-list`       | 列出所有打开的终端标签页（id、标题、工作目录、活动状态）                              | —                                                                 |

| 参数                | 类型           | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`            | string（必填） | 生成描述；提供参考图时为编辑指令（**一次调用 = 一张图**；需要多张图请并行发起多次调用）                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `prompts`           | array          | **兼容保留，不推荐**：逐请求不同提示词（1-8 项，覆盖 `n`）。生成多张**各不相同**的图片请**并行发起多次调用**（每次一张、各自独立的 `prompt`），不要用本参数在单次调用里塞多个提示词                                                                                                                                                                                                                                                                                             |
| `images`            | array          | 参考图 `[{data, mimeType}]`（base64，不含 `data:` 前缀；兼容带前缀的 data URL）或 `[{path, mimeType}]`。`path` 可为可信的绝对磁盘路径，或来自 `[Reference image #N for imagegen-generate: ...]` 引用块的安全 `upload/...` 相对路径；相对路径必须以 `upload/` 开头并拒绝 `..` 穿越，服务端会自动读取并编码，无需复制大段 base64。图生图/编辑用；运行时每组上限 **14 张**、单张编码数据约 20 MiB（工具描述建议 AI 单次 ≤5 张，仅为兼容部分服务商更严格的限制）；OpenAI 走 `/images/edits`、Gemini 走 `inlineData`；提供 `requestImages` 时被忽略 |
| `requestImages`     | array          | **兼容保留，不推荐**：逐请求独立参考图组 ``[[组1...], [组2...], ...]``（每组的形状同 `images`），组数必须 = 请求数（= `prompts` 长度或 `n`，1-8）。多张不同源图分别编辑/重绘请**并行发起多次调用**（每次一张、各自带独立的 `images`）；未提供时所有请求共用 `images` |
| `model`             | string         | 覆盖设置中的模型；OpenAI：`gpt-image-1`/`gpt-image-2`/`dall-e-3`；Gemini：`gemini-3.1-flash-image`（Nano Banana 2）/`gemini-3.1-flash-lite-image`（Lite）/`gemini-3-pro-image`（Pro）/`gemini-2.5-flash-image`（旧版）。**能力规则（不支持的请求会 400）**：`dall-e-3` 仅文生图（不接受参考图）且每次仅生成 1 张；`imagen-*` 同样仅文生图                                                                                                                                                    |
| `provider`          | enum           | `auto`（默认，按配置推导）/ `openai` / `gemini`，后端切换                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `size`              | string         | OpenAI：`1024x1024`、`1024x1536`、`1536x1024` 等；Gemini：`1K`/`2K`/`4K`（imageSize）或 `16:9`、`1:1`、`9:16` 等（aspectRatio）                                                                                                                                                                                                                                                                                                                                                              |
| `quality`           | enum           | `low` / `medium` / `high` / `auto`；OpenAI 仅 gpt-image 系列生效，Gemini 仅接受 `low`/`medium`/`high`（`auto` 被忽略）                                                                                                                                                                                                                                                                                                                                                                       |
| `outputFormat`      | enum           | OpenAI：`png`（默认）/ `jpeg` / `webp`；dall-e 与 Gemini 忽略                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `outputCompression` | number         | OpenAI JPEG/WebP 压缩率 0-100                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `n`                 | number            | **兼容保留，不推荐**：1-8（默认 1）。生成多张图片请**并行发起多次调用**（每次一张），不要调大 `n`；n>1 仅对**同一提示词**拆成 n 个**并发子请求**（每请求 1 张，绕开上游不支持单请求多图），整批返回并各自落库；n>1 时自动关闭流式预览；`dall-e-3` 恒为 1。传 `prompts` 数组时由数组长度决定请求数 |
| `personGeneration`  | enum           | Gemini：`dont_allow`（默认）/ `allow_all` / `allow_adult`                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `webSearch`         | boolean        | Gemini 联网搜索（Grounding with Google Search），默认取设置                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `stream`            | boolean        | 流式预览（OpenAI `partial_images` SSE / Gemini `streamGenerateContent`），默认取设置；dall-e 与图生图忽略                                                                                                                                                                                                                                                                                                                                                                                    |
| `inputFidelity`     | enum           | OpenAI 编辑保真度：`low` / `high` / `auto`（默认）；`gpt-image-2` 不支持（恒为高保真）                                                                                                                                                                                                                                                                                                                                                                                                       |
| `background`        | enum           | OpenAI：`opaque`（默认）/ `transparent` / `auto`；透明背景需模型支持（`gpt-image-2` 等不支持时自动降级为 `opaque`）                                                                                                                                                                                                                                                                                                                                                                          |
| `moderation`        | enum           | OpenAI：`auto`（默认）/ `low`（更宽松过滤）                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `seed`              | number         | 确定性种子，复现结果                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `thinkingLevel`     | enum           | Gemini 3.1 Flash Image：`minimal`（默认，快）/ `high`（质量更高，慢）                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `imageSearch`       | boolean        | Gemini 3.1 Flash Image：Google Image Search 联网参考（需展示搜索建议）                                                                                                                                                                                                                                                                                                                                                                                                                       |

> **配置与暴露规则**：渠道需 `enabled` + `apiKey` + `model` 三者齐备才算可用；
> 多个渠道可同时启用，AI 按请求选择（未指定渠道时按渠道顺序取第一个可用渠道，也可传 `provider` 指定）；
> 均未配置时 `imagegen-generate` 从模型工具列表隐藏。
> 不支持的模型能力会在**发送前**自动校验（`dall-e-3`/`imagen-*` 传参考图
> 本地拦截并提示换模型；`dall-e-3` 的 `n` 自动收敛为 1）；仍出现的上游 400
> 会附带具体修复提示（多图数量 / 图像输入 / 尺寸 / 质量）。
> 图形界面配置见 [2-使用指南/9-图像生成](../2-使用指南/9-图像生成.md)；
> 也可通过 `config` 工具的 `imagegen` scope 读写（见上文，apiKey 脱敏）；
> 多图生成通过**并行多次调用**实现（一次调用 = 一张图），受设置中的「最大并发生成数」限制（1-8，默认 4），超出排队、完成一张补一张；`n`/`prompts`/`requestImages` 为兼容保留参数，不推荐使用。
> **Imagen 已弃用**：`imagen-*` 模型 2026-08-17 关停，请用 Nano Banana 系列。

### skills

| 工具全名               | 用途               | 关键参数 |
| ---------------------- | ------------------ | -------- |
| `skills-skill-execute` | 加载并执行指定技能 | `skill`  |

> 注意：frontmatter 中控制开关的字段名是 `enable`（不是 `enabled`）。
> 历史上的 `skills-config-*` 工具（list/setEnabled/installGithub/uninstall）
> 已移除，技能管理统一使用 `config` 服务器的 `skills` scope（见上文）。

## 5. 与外部 MCP 工具的区别

外部 MCP 服务器工具由用户在 **MCP 设置** 中添加
（见 [2-使用指南/1-配置 MCP 服务器](../2-使用指南/1-配置MCP服务器.md)），
工具名前缀为服务器名（如 `dbx-search_context`），与内置工具通过
内置服务器列表前缀匹配的方式区分。
