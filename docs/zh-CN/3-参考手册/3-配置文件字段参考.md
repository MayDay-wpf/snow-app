# 3-配置文件字段参考（Config File Field Reference）

本文档列出 `~/.snow/` 下全部配置文件的字段结构，供手动编辑或通过
`config` 工具读写时核对。`config` 工具的白名单与本文档保持一致：
文件型配置写后**可能需要重启应用或 UI 重存生效**（`settings.mcpServers`
除外——它自动同步应用数据库立即生效）。

> 各文件的读写方式（`config-manage` 的 `action=get`/`action=set` 的 scope 名）见
> [2-内置工具参考](./2-内置工具参考.md) 的「支持的配置域」。

## 1. settings.json（scope: `settings`）

与 Snow CLI 共享的全局配置文件。顶层字段见
[1-settings.json配置参考](./1-settings.json配置参考.md)：

| 字段                       | 类型    | 说明                                                                                  |
| -------------------------- | ------- | ------------------------------------------------------------------------------------- |
| `mcpServers`               | object  | 全局 MCP 服务器，键为服务器名                                                         |
| `codebase`                 | object  | 代码库语义搜索配置                                                                    |
| `sensitiveCommands`        | array   | 敏感命令拦截规则                                                                      |
| `yoloMode`                 | boolean | 无确认模式                                                                            |
| `vulnerabilityHuntingMode` | boolean | 漏洞狩猎模式                                                                          |
| `toolSearchEnabled`        | boolean | 旧版共享字段；Snow App 的插件工具搜索不再读取此开关，随项目有效启用的工具插件自动生效 |
| `hybridCompressEnabled`    | boolean | 混合压缩开关                                                                          |
| `teamMode`                 | boolean | 团队模式                                                                              |
| `goal`                     | object  | Goal 模式配置（`defaultTokenBudgetM`：默认 token 预算，单位百万）                     |
| `ultraTodoEnabled`         | boolean | 超长 TODO 列表开关                                                                    |

## 2. config.json（scope: `snowcfg`）

API 密钥与模型配置，统一保存在 `snowcfg` 对象下（与 Snow CLI 共享）。

| 字段                    | 类型    | 敏感 | 说明                                                                                                                                    |
| ----------------------- | ------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `baseUrl`               | string  |      | 主服务端点地址                                                                                                                          |
| `baseUrlMode`           | string  |      | `auto` 自动 / `custom` 手动                                                                                                             |
| `apiKey`                | string  | 🔒   | 主服务商密钥                                                                                                                            |
| `requestMethod`         | string  |      | 请求方法，如 `chat`                                                                                                                     |
| `advancedModel`         | string  |      | Profile 的默认高级模型；普通会话仍使用会话选定模型                                                                                      |
| `basicModel`            | string  |      | 会话标题、AI Commit、`@?` 文件搜索和代码库 Agent Review 使用的模型                                                                      |
| `supportsVision`        | boolean |      | 主模型是否支持视觉                                                                                                                      |
| `visionBaseUrl`         | string  |      | 视觉服务端点                                                                                                                            |
| `visionBaseUrlMode`     | string  |      | 视觉端点模式                                                                                                                            |
| `visionApiKey`          | string  | 🔒   | 视觉服务密钥                                                                                                                            |
| `visionRequestMethod`   | string  |      | 视觉请求方法                                                                                                                            |
| `visionModel`           | string  |      | 视觉模型名                                                                                                                              |
| `maxContextTokens`      | integer |      | 最大上下文 token 数                                                                                                                     |
| `maxTokens`             | integer |      | 单次生成最大 token 数                                                                                                                   |
| `showThinking`          | boolean |      | 是否展示思考过程                                                                                                                        |
| `streamIdleTimeoutSec`  | integer |      | 流式响应空闲超时（秒），留空为 60；首个数据到达前的等待窗口会按请求体体积自动放宽，并随空闲超时重试递增；大附件或经慢速中转时建议 ≥ 300 |
| `maxRetries`            | integer |      | 请求最大重试次数                                                                                                                        |
| `retryDelayMs`          | integer |      | 重试间隔（毫秒）；留 0 走指数退避                                                                                                       |
| `enableAutoCompress`    | boolean |      | 自动压缩开关                                                                                                                            |
| `autoCompressThreshold` | integer |      | 自动压缩阈值（百分比）                                                                                                                  |
| `toolResultTokenLimit`  | integer |      | 工具结果最多占模型上下文的百分比                                                                                                        |
| `anthropicBeta`         | boolean |      | Anthropic Beta 头开关                                                                                                                   |
| `streamingDisplay`      | boolean |      | 流式显示开关                                                                                                                            |
| `systemPromptId`        | string  |      | 当前系统提示词 id                                                                                                                       |
| `customHeadersSchemeId` | string  |      | 当前自定义请求头方案 id                                                                                                                 |
| `anthropicCacheTTL`     | string  |      | Anthropic 缓存 TTL，如 `5m`                                                                                                             |
| `responsesReasoning`    | object  |      | Responses 推理配置（`{enabled, effort}`）                                                                                               |
| `responsesVerbosity`    | string  |      | Responses 输出详细度，如 `medium`                                                                                                       |
| `responsesFastMode`     | boolean |      | Responses 快速模式                                                                                                                      |
| `responsesWebSocket`    | boolean |      | Responses WebSocket 传输（复用连接，替代 SSE）                                                                                          |
| `chatThinking`          | object  |      | 思考强度配置（`{enabled, reasoning_effort}`）                                                                                           |

> **模型路由与 Profile 完整性**：Snow App 不按提示词复杂度在
> `basicModel` 和 `advancedModel` 间自动切换。普通会话使用会话选定模型，
> `advancedModel` 只作为所属 Profile 的默认高级模型；`basicModel` 供会话标题、
> AI Commit、`@?` 文件搜索和代码库 Agent Review 使用，两类模型不互相回退。
> 标题使用会话绑定 Profile；绑定档案删除后按普通会话规则回退 active Profile。
> active Profile 的 `advancedModel` 与 `basicModel` 在 trim 后都必须非空；
> inactive 草稿可留空，API Key 不参与这项模型完整性校验。视觉理解、图像生成和
> embedding 使用独立配置与通道。

## 3. proxy-config.json（scope: `proxy`）

代理与浏览器配置。

| 字段               | 类型    | 说明                                 |
| ------------------ | ------- | ------------------------------------ |
| `enabled`          | boolean | 代理开关                             |
| `host`             | string  | 代理主机，如 `127.0.0.1`             |
| `port`             | integer | 代理端口，如 `7890`                  |
| `searchEngine`     | string  | 搜索服务商，如 `bing` / `duckduckgo` |
| `browserPath`      | string  | 浏览器可执行文件路径                 |

## 5. custom-headers.json（scope: `custom-headers`）

自定义请求头方案（🔒 读取时脱敏）。

> **这是 Snow CLI 兼容的同步源文件，不是 App 的运行配置。** Snow App 运行时按
> 应用数据库表 `custom_header_schemes`（与「设置 → 自定义请求头」面板同源）注入
> 请求头；只改本文件不会改变 App 实际发送的请求头，需在设置面板点「同步 Snow CLI
> 自定义请求头」才会导入。要让 AI 直接改 App 生效的请求头，请用
> `config-manage action=set scope=customHeaderSchemes`（详见 [内置工具参考](2-内置工具参考.md#config)）。

| 字段      | 类型   | 敏感 | 说明                                                                                                                    |
| --------- | ------ | ---- | ----------------------------------------------------------------------------------------------------------------------- |
| `active`  | string |      | 当前激活的方案 id                                                                                                       |
| `schemes` | array  | 🔒   | 方案数组，元素：`{id, name, headers, createdAt}`；`headers` 为 `{请求头名: 值}` 映射（可能含 `Authorization` 等敏感头） |

请求头值中可使用会话 ID 占位符（6 种等价写法：`{{session_id}}`、`{{sessionId}}`、`{{conversation_id}}`、`{{conversationId}}`、`${session_id}`、`${conversation_id}`），发送请求时按该请求所属会话 ID 展开，可与其它文本组合（如 `snow-app-{{session_id}}`）；无会话上下文的请求（如获取模型列表）会省略该请求头（详见「个性化、主题与快捷键」指南）。

## 10. lsp-config（scope: `lsp-config`）

LSP（Language Server Protocol）服务器配置：声明 Snow App 为各语言
可启动的外部语言服务器及其参数。

> **当前状态：DB-backed 配置域（应用数据库 `lsp_server_configs` 表 + 项目级
> system_settings JSON）。**
> 已无 `~/.snow/lsp-config.json` 文件；`config` 工具直读写表（立即生效，
> 无需重启）。旧文件在首次启动时一次性迁移导入（source=legacy）。
> `config-manage action=set` 为全量替换语义（与原文件型一致），写入时深度校验。
> 语言服务器由 `lsp` MCP 服务消费（`lsp-diagnostics` / `lsp-hover` /
> `lsp-definition` / `lsp-references` / `lsp-symbols` / `lsp-format`，见
> [2-使用指南/7-代码库索引与代码诊断](../2-使用指南/7-代码库索引与代码诊断.md)）。

| 字段            | 类型    | 说明                                                          |
| --------------- | ------- | ------------------------------------------------------------- |
| `schemaVersion` | integer | 结构版本                                                      |
| `servers`       | object  | 语言服务器映射，键为语言标识（如 `typescript`），值结构见下表 |

`servers.<语言>` 值结构（写入时按以下规则做深层校验，未知字段放行以保持前向兼容）：

| 字段                    | 类型            | 说明                                                                       |
| ----------------------- | --------------- | -------------------------------------------------------------------------- |
| `command`               | string          | 启动语言服务器的可执行命令（如 `typescript-language-server`）              |
| `args`                  | array\<string\> | 启动参数（如 `["--stdio"]`）                                               |
| `fileExtensions`        | array\<string\> | 该服务器负责的文件扩展名（如 `[".ts", ".tsx"]`）                           |
| `installCommand`        | string          | 服务器未安装时的安装命令（如 `npm install -g typescript-language-server`） |
| `initializationOptions` | object          | 随 LSP `initialize` 请求发送给服务器的初始化选项                           |

示例：

```json
{
  "schemaVersion": 1,
  "servers": {
    "typescript": {
      "command": "typescript-language-server",
      "args": ["--stdio"],
      "fileExtensions": [".ts", ".tsx", ".js", ".jsx"],
      "installCommand": "npm install -g typescript-language-server typescript",
      "initializationOptions": {}
    }
  }
}
```

通过 `config` 工具读写（键级替换、写前深层校验、自动备份与原子写）：

```text
config-manage action=get    scope="lsp-config" key="servers"              # 读取当前配置
config-manage action=list   scope="lsp-config"                             # 查看键与当前值
config-manage action=set    scope="lsp-config" key="servers" value={...}   # 写入（校验各字段类型）
config-manage action=delete scope="lsp-config" key="servers"             # 删除（需用户确认）
```

**项目级配置**（Phase 3）：`lsp-config` 支持 `projectId` 参数（与
subAgents/hooks 一致）——传入后读写该项目的独立配置，**覆盖**全局同语言：

```text
config-manage action=set    scope="lsp-config" projectId="local:E:\code\snow-app" key="servers" value={...}
config-manage action=get    scope="lsp-config" projectId="local:E:\code\snow-app" key="servers"
config-manage action=delete scope="lsp-config" projectId="local:E:\code\snow-app" key="servers"  # 需用户确认
```

> 项目级配置存储在应用数据库 system_settings（键前缀
> `project_lsp_server_configs_`）；`lsp` 服务消费时按 (语言 × 项目根) 取
> 有效配置（项目优先）。`config-manage action=set` 立即生效，无需重启。
